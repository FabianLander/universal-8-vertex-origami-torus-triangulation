# A Universal 8-Vertex Origami Torus Triangulation

The Mathematica calculations for the paper *A Universal 8-Vertex Origami Torus Triangulation* by Peter G. Doyle, Fabian Lander, Richard Evan Schwartz and Steve Trettel.

    wolframscript -file UniversalityProof.m

Or open `UniversalityProof.m` in Mathematica and evaluate it. All arithmetic is exact.
